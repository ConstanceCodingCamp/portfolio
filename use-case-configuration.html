DNS & Configuration Investigation

Part of a single documented investigation of the susienewton.com HTTPS certificate incident.

Situation

GitHub Pages showed DNS verification pending and no certificate issued, while GoDaddy managed the domain DNS.

Task

Determine whether website DNS and custom-domain settings aligned without disrupting business email.

Action

Verified four standard GitHub Pages apex A records; identified www CNAME pointing to susienewton.com; changed only www to constancecodingcamp.github.io; preserved email-related records.

Result & evidence

GoDaddy confirmed the record update, and GitHub subsequently reported DNS check successful. The earlier CNAME configuration was a plausible contributor, not independently proven as the sole root cause.

This is an STS-owned website incident, not a third-party client case. Outcomes are limited to the evidence observed during troubleshooting.
