Verification & Preventive Controls

Part of a single documented investigation of the susienewton.com HTTPS certificate incident.

Situation

After DNS changes, HTTPS needed verification before the incident could be closed.

Task

Verify the visible fix and identify preventive checks.

Action

Observed GitHub Pages DNS check successful and Enforce HTTPS enabled; retested the website and Instagram profile link in a browser; evaluated monitoring options.

Result & evidence

The browser retests showed no certificate warning and GitHub displayed HTTPS enforcement. Independent certificate-chain testing and external alert testing were not documented as completed.

This is an STS-owned website incident, not a third-party client case. Outcomes are limited to the evidence observed during troubleshooting.
